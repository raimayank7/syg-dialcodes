How to dial a number in another country

  1. Dial your exit code. In India it is 00. On a mobile, + works everywhere.
  2. Dial the country code from this site.
  3. Dial the number, leaving out the 0 that locals dial first.

Each country page shows the code, the shape and length of its numbers, the exit code used there, and the local time now, so you do not call at midnight.

Common questions

What is a country code?

A country code is the one to three digits you dial after the exit code to reach another country. India is 91, the United States and Canada are 1, the United Kingdom is 44.

Is +1 only the United States?

+1 is shared by 25 countries and territories, including the United States, Canada and many Caribbean islands. The three digits after the 1 show which place it is.

What does the + in a phone number mean?

It stands for the exit code of whichever country you are in. On a mobile phone, press and hold 0 to type it.

Which code do I use to save a number for WhatsApp?

Save it as + then the country code then the number without its leading 0, for example +91 and the ten digits for India.
