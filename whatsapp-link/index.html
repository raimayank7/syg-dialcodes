WhatsApp link maker: chat without saving the number

Type a phone number and get a wa.me link that opens a WhatsApp chat with it. Useful for a number you will message once, or to put a "chat with us" link on a card, bill or page.

Nothing you type leaves your device. The link is made in your browser.

How it works

  1. Choose the country of the number. India is chosen to begin with.
  2. Type the number. Spaces, dashes and a leading 0 are fine; the tool removes them. If the number already starts with +, the country choice is ignored.
  3. Tap Make the link, then copy it or open the chat.

What a WhatsApp link looks like

The link is https://wa.me/ followed by the full number in international format: country code and number, with no +, no zeros in front, no spaces and no brackets. For an Indian mobile that is wa.me/91 and the ten digits. A message can be added at the end after ?text=.

Where such a link helps

  • A one-time message to a delivery person, a seller or an office, without filling your contacts with numbers you will never use again.
  • A shop or service: put the link behind a "Chat with us" button, in a social media profile, in an email signature or as a QR code on a bill or visiting card.
  • A ready message: add the starting text, such as "I want to know about my order", so customers only have to press send.

Getting the number right

Almost every link that fails has one of three faults: the country code is missing, the 0 that people dial inside the country was left in, or a digit was dropped while copying. A full international number has between 7 and 15 digits counting the country code, and the tool refuses anything outside that. If you are not sure of the code or of how long a number should be, open the country in the country list: each page shows the code, the trunk prefix to leave out and the usual length of a mobile number.

Common questions

Does the other person see anything when I make a link?

No. Making a link does nothing on its own. A chat opens only when someone taps the link, and a message is sent only when they press send.

Why does the link say the number is not on WhatsApp?

Either the number does not use WhatsApp, or the country code is wrong. Check the country you chose and that no digit is missing.

Is this tool part of WhatsApp?

No. This is an independent tool. It only writes the link in the format that WhatsApp publishes for its click to chat feature.
