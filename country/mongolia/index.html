Mongolia country code: +976

The calling code of Mongolia is +976. Below: how to dial a number there from India or from any other country, how long the numbers are, and what time it is there now.

How to call Mongolia from India

  1. Dial 00, the exit code of India. On a mobile phone you can press and hold 0 to type + instead.
  2. Dial 976, the country code of Mongolia.
  3. Dial the rest of the number. If the number is written with 0 in front for calls inside Mongolia, leave that 0 out.

So a mobile number shaped like +976 8XXX XXXX is dialled from an Indian landline as 00 976 8XXX XXXX, and from any mobile phone as +976 8XXX XXXX. The X marks stand for the digits of the real number.

How to call Mongolia from other countries

The steps are the same everywhere: your own country's exit code, then 976, then the number. The exit code is 011 from the United States and Canada, 00 from most of Europe, Africa and Asia, and 0011 from Australia. A mobile phone accepts + in place of any exit code, which is why numbers are best saved as +976 followed by the number.

How to call India from Mongolia

Dial 001 (the exit code of Mongolia), then 91 for India, then the number. An Indian mobile number has 10 digits. For an Indian landline, dial the STD code without its leading 0, then the number: for example 001 91 11 and the eight-digit number for Delhi. Find an Indian STD code.

Saving a number from Mongolia for WhatsApp

WhatsApp needs the full international number: + then 976 then the number, without the trunk prefix 0. Save the contact that way and it will work on WhatsApp from any country. To open a chat without saving the contact, use the WhatsApp link maker.
