How to call Togo from India

  1. Dial 00, the exit code of India. On a mobile phone you can press and hold 0 to type + instead.
  2. Dial 228, the country code of Togo.
  3. Dial the rest of the number. Numbers in Togo have no trunk prefix, so dial every digit of the number as it is written.

So a mobile number shaped like +228 9X XX XX XX is dialled from an Indian landline as 00 228 9X XX XX XX, and from any mobile phone as +228 9X XX XX XX. The X marks stand for the digits of the real number.

How to call Togo from other countries

The steps are the same everywhere: your own country's exit code, then 228, then the number. The exit code is 011 from the United States and Canada, 00 from most of Europe, Africa and Asia, and 0011 from Australia. A mobile phone accepts + in place of any exit code, which is why numbers are best saved as +228 followed by the number.

How to call India from Togo

Dial 00 (the exit code of Togo), then 91 for India, then the number. An Indian mobile number has 10 digits. For an Indian landline, dial the STD code without its leading 0, then the number: for example 00 91 11 and the eight-digit number for Delhi. Find an Indian STD code.

Saving a number from Togo for WhatsApp

WhatsApp needs the full international number: + then 228 then the number. Save the contact that way and it will work on WhatsApp from any country. To open a chat without saving the contact, use the WhatsApp link maker.
