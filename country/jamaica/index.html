How to call Jamaica from India

  1. Dial 00, the exit code of India. On a mobile phone you can press and hold 0 to type + instead.
  2. Dial 1, the country code of Jamaica.
  3. Dial the rest of the number.

So a mobile number shaped like +1 8XX-XXX-XXXX is dialled from an Indian landline as 00 1 8XX-XXX-XXXX, and from any mobile phone as +1 8XX-XXX-XXXX. The X marks stand for the digits of the real number.

How to call Jamaica from other countries

The steps are the same everywhere: your own country's exit code, then 1, then the number. The exit code is 011 from the United States and Canada, 00 from most of Europe, Africa and Asia, and 0011 from Australia. A mobile phone accepts + in place of any exit code, which is why numbers are best saved as +1 followed by the number.

How to call India from Jamaica

Dial 011 (the exit code of Jamaica), then 91 for India, then the number. An Indian mobile number has 10 digits. For an Indian landline, dial the STD code without its leading 0, then the number: for example 011 91 11 and the eight-digit number for Delhi. Find an Indian STD code.

Who else uses +1

+1 is shared by 25 countries and territories of the North American Numbering Plan. Each one is told apart by the three-digit area code that follows the 1. A call between two of them is dialled like a national call (1, area code, number), but it may still be charged as an international call.

Saving a number from Jamaica for WhatsApp

WhatsApp needs the full international number: + then 1 then the number. Save the contact that way and it will work on WhatsApp from any country. To open a chat without saving the contact, use the WhatsApp link maker.
