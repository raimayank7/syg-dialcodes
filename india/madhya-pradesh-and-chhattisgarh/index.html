How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Indore that is 0731 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 731 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Indore (0731), Khandwa (0733), Ujjain (0734), Gwalior (0751), Bhopal (0755).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.

The codes of Madhya Pradesh and Chhattisgarh in brief

This page lists 361 places under Madhya Pradesh and Chhattisgarh, with 361 different codes between them. Counted without the leading 0: 8 have a three-digit code, so their landline numbers have seven digits and 353 have a four-digit code, so their landline numbers have six digits. The lowest code is 07141 (Betul) and the highest is 0788 (Durg).

How the codes are numbered

After the 0, the codes begin with 77 (75 places, such as Ajaigarh), 76 (71 places, such as Amarpatan), 75 (59 places, such as Ambah), 78 (55 places, such as Antagarh), 73 (34 places, such as Agar) and 74 (27 places, such as Alot). Another 2 two-digit beginnings have fewer places. STD codes are given out by region, so neighbours tend to share a first digit. The first digit 7 is also used in Gujarat, Maharashtra and Rajasthan.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town. 4 places appear under more than one code: Damoh (07638, 07812), Manpur (07627, 07703, 07746) and Patan (07621, 07826). A name can belong to two different towns, so check the district with the person you are calling.

Questions about STD codes in Madhya Pradesh and Chhattisgarh

What is the STD code of Indore?

The STD code of Indore is 0731. From outside India, dial +91 731 and then the landline number.

How many digits does a landline number in Madhya Pradesh and Chhattisgarh have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Madhya Pradesh and Chhattisgarh have the shortest STD codes?

Indore (0731), Khandwa (0733) and Ujjain (0734).
