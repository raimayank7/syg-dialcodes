How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Rourkela that is 0661 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 661 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Rourkela (0661), Sambalpur (0663), Cuttack (0671), Bhubaneshwar (0674), Berhampur (0680).

Spellings are as in the source. Where two names share a row, the code serves both places. If a code does not work, ask your phone company.
