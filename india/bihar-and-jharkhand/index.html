How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Dhanbad that is 0326 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 326 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Dhanbad (0326), Patna (0612), Muzaffarpur (0621), Gaya (0631), Bhagalpur (0641).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.

Source: the India area-code data of Google libphonenumber, which follows the National Numbering Plan 2003 of the Department of Telecommunications. Checked in November 2026. Spellings are as in the source. Where two names share a row, the code serves both places. If a code does not work, ask your phone company.
