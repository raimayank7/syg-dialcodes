How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Imphal that is 0385 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 385 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Imphal (0385), Ukhrul Central (03845), Thonbal (03848), Ukhrursouth / Kassemkhulen (03870), Mao / Korang (03871).
