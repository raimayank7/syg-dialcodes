How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Lungleh that is 0372 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 372 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Lungleh (0372), Aizawal (0389), Champai / Chiapui (03830), Champa (03831), Demagiri (03834).

The codes of Mizoram in brief

This page lists 9 places under Mizoram, with 9 different codes between them. Counted without the leading 0: 2 have a three-digit code, so their landline numbers have seven digits and 7 have a four-digit code, so their landline numbers have six digits. The lowest code is 0372 (Lungleh) and the highest is 0389 (Aizawal).

How the codes are numbered

After the 0, the codes begin with 38 (8 places, such as Aizawal) and 37 (1 place, such as Lungleh). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 3 is also used in Andaman and Nicobar Islands, Arunachal Pradesh, Assam, Bihar and Jharkhand, Manipur, Meghalaya, Nagaland and Rajasthan and 2 more lists.

Shared codes

3 rows name of the table two or more places that share one code, written with a slash between the names: Champai and Chiapui (03830), Saiha and Tuipang (03836) and Aizwal and Serchip (03838). The same code is dialled for each of them.

Questions about STD codes in Mizoram

What is the STD code of Lungleh?

The STD code of Lungleh is 0372. From outside India, dial +91 372 and then the landline number.

How many digits does a landline number in Mizoram have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Mizoram have the shortest STD codes?

Lungleh (0372), Aizawal (0389) and Champai / Chiapui (03830).
