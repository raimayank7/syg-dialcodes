How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Guwahati that is 0361 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 361 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Guwahati (0361), Dibrugarh (0373), Tinsukhia (0374), Jorhat (0376), Boko (03621).
