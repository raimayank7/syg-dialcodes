How STD dialling works

  • STD stands for Subscriber Trunk Dialling: calling a landline in another town without an operator.
  • An STD code is written with a 0 in front, like 0161. The 0 is the trunk prefix; the code itself is 161.
  • The code (without 0) and the landline number together are always 10 digits. So a city with a 2-digit code has 8-digit numbers, and a town with a 4-digit code has 6-digit numbers.
  • From a mobile phone, always dial the 0, the code and the number, even for a landline in your own town.
  • From a landline, calls to any mobile number need a 0 in front of the 10 digits. This rule began on 15 January 2021.
  • From abroad, dial +91, drop the 0, then the code and the number.

Common questions

What is an STD code?

An STD code is the area code of a town in India. You dial it before a landline number when you call from another town or from a mobile phone.

Do mobile numbers have an STD code?

No. An Indian mobile number is 10 digits and is dialled as it is from anywhere in India.

How do I dial an Indian landline from abroad?

Dial +91, then the STD code without its leading 0, then the landline number.
