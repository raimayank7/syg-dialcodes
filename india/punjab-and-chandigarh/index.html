How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Kharar that is 0160 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 160 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Kharar (0160), Ludhiana (0161), Bhatinda (0164), Chandigarh (0172), Patiala (0175).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.
