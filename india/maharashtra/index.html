How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Pune that is 020 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 20 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Pune (020), Mumbai (022), Chinchwad (0212), Navi Mumbai / Turbhe (0215), Sholapur (0217).
