How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Ghaziabad / Dadri that is 0120 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 120 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Ghaziabad / Dadri (0120), Meerut (0121), Hapur (0122), Muzaffarnagar (0131), Saharanpur (0132).
