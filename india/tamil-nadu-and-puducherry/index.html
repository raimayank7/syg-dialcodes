How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Chennai that is 044 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 44 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Chennai (044), Pondicherry (0413), Vellore (0416), Tirupur (0421), Coimbatore (0422).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.

The codes of Tamil Nadu and Puducherry in brief

This page lists 130 places under Tamil Nadu and Puducherry, with 130 different codes between them. Counted without the leading 0: 1 has a two-digit code, so its landline numbers have eight digits, 13 have a three-digit code, so their landline numbers have seven digits and 116 have a four-digit code, so their landline numbers have six digits. The lowest code is 04111 (Sriperumbudur) and the highest is 04652 (Nagercoil).

How the codes are numbered

After the 0, the codes begin with 43 (32 places, such as Arantangi), 42 (31 places, such as Anamalai), 41 (29 places, such as Arakandanallur), 45 (24 places, such as Aruppukottai), 46 (13 places, such as Ambasamudram) and 44 (1 place, such as Chennai). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 4 is also used in Andhra Pradesh and Telangana, Kerala and Lakshadweep.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town.

Questions about STD codes in Tamil Nadu and Puducherry

What is the STD code of Chennai?

The STD code of Chennai is 044. From outside India, dial +91 44 and then the landline number.

How many digits does a landline number in Tamil Nadu and Puducherry have?

It depends on the code: eight digits with a two-digit code, seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Tamil Nadu and Puducherry have the shortest STD codes?

Chennai (044), Pondicherry (0413) and Vellore (0416).
