How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Shimla that is 0177 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 177 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Shimla (0177), Nahan (01702), Paonta (01704), Rohru (01781), Rampur Bushahar (01782).
