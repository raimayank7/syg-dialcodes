How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Kolkata that is 033 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 33 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Kolkata (033), Asansol (0341), Burdwan (0342), Durgapur (0343), Siliguri (0353).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.

The codes of West Bengal and Sikkim in brief

This page lists 72 places under West Bengal and Sikkim, with 72 different codes between them. Counted without the leading 0: 1 has a two-digit code, so its landline numbers have eight digits, 5 have a three-digit code, so their landline numbers have seven digits and 66 have a four-digit code, so their landline numbers have six digits. The lowest code is 03174 (Diamond Harbour) and the highest is 03595 (Gauzing / Nayabazar).

How the codes are numbered

After the 0, the codes begin with 32 (26 places, such as Adra), 35 (24 places, such as Alipurduar), 34 (20 places, such as Asansol), 31 (1 place, such as Diamond Harbour) and 33 (1 place, such as Kolkata). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 3 is also used in Andaman and Nicobar Islands, Arunachal Pradesh, Assam, Bihar and Jharkhand, Manipur, Meghalaya, Mizoram and Nagaland and 2 more lists.

Shared codes

3 rows name of the table two or more places that share one code, written with a slash between the names: Nayagarh and Kultikri (03223), Murshidabad and Jiaganj (03483) and Gauzing and Nayabazar (03595). The same code is dialled for each of them. One place appears under more than one code: Islampur (03481, 03526). A name can belong to two different towns, so check the district with the person you are calling.

Questions about STD codes in West Bengal and Sikkim

What is the STD code of Kolkata?

The STD code of Kolkata is 033. From outside India, dial +91 33 and then the landline number.

How many digits does a landline number in West Bengal and Sikkim have?

It depends on the code: eight digits with a two-digit code, seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in West Bengal and Sikkim have the shortest STD codes?

Kolkata (033), Asansol (0341) and Burdwan (0342).
