How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Itanagar / Ziro that is 0360 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 360 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Itanagar / Ziro (0360), Passighat (0368), Yangkiyang (03777), Pakkekesang (03778), Roing / Mariso (03779).

The codes of Arunachal Pradesh in brief

This page lists 33 places under Arunachal Pradesh, with 33 different codes between them. Counted without the leading 0: 2 have a three-digit code, so their landline numbers have seven digits and 31 have a four-digit code, so their landline numbers have six digits. The lowest code is 0360 (Itanagar / Ziro) and the highest is 03809 (Sagalee).

How the codes are numbered

After the 0, the codes begin with 37 (21 places, such as Along), 38 (10 places, such as Anini) and 36 (2 places, such as Itanagar / Ziro). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 3 is also used in Andaman and Nicobar Islands, Assam, Bihar and Jharkhand, Manipur, Meghalaya, Mizoram, Nagaland and Rajasthan and 2 more lists.

Shared codes

4 rows name of the table two or more places that share one code, written with a slash between the names: Itanagar and Ziro (0360), Roing and Mariso (03779) and Kalaktung and Bomdila (03782). The same code is dialled for each of them.

Questions about STD codes in Arunachal Pradesh

What is the STD code of Itanagar / Ziro?

The STD code of Itanagar / Ziro is 0360. From outside India, dial +91 360 and then the landline number.

How many digits does a landline number in Arunachal Pradesh have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Arunachal Pradesh have the shortest STD codes?

Itanagar / Ziro (0360), Passighat (0368) and Yangkiyang (03777).
