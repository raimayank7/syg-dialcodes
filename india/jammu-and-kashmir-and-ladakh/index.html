How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Jammu that is 0191 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 191 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Jammu (0191), Srinagar (0194), Basholi (01921), Kathua (01922), Samba (01923).

This list keeps the grouping of the telecom numbering plan, which is why two states or territories share this page.

The codes of Jammu and Kashmir, and Ladakh in brief

This page lists 34 places under Jammu and Kashmir, and Ladakh, with 34 different codes between them. Counted without the leading 0: 2 have a three-digit code, so their landline numbers have seven digits and 32 have a four-digit code, so their landline numbers have six digits. The lowest code is 0191 (Jammu) and the highest is 01999 (Mahore).

How the codes are numbered

All the codes begin with 19 after the 0. STD codes are given out by region, so neighbours tend to share a first digit. The first digit 1 is also used in Delhi, Haryana, Himachal Pradesh, Punjab and Chandigarh, Rajasthan, Uttar Pradesh and Uttarakhand.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town.

Questions about STD codes in Jammu and Kashmir, and Ladakh

What is the STD code of Jammu?

The STD code of Jammu is 0191. From outside India, dial +91 191 and then the landline number.

How many digits does a landline number in Jammu and Kashmir, and Ladakh have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Jammu and Kashmir, and Ladakh have the shortest STD codes?

Jammu (0191), Srinagar (0194) and Basholi (01921).
