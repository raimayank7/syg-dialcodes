How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Dehradun that is 0135 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 135 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits. Shorter codes belong to bigger cities: Dehradun (0135), Roorkee (01332), Roorkee / Haridwar (01334), Pauri / Bubakhal (01346), Lansdowne / Syunsi (01348).

Source: the India area-code data of Google libphonenumber, which follows the National Numbering Plan 2003 of the Department of Telecommunications. Checked in November 2026. Spellings are as in the source. Where two names share a row, the code serves both places. If a code does not work, ask your phone company.
