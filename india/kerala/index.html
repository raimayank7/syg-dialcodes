How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Taliparamba that is 0460 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 460 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Taliparamba (0460), Tiruvalla (0469), Attingal (0470), Thiruvananthapuram (0471), Kollam (0474).

The codes of Kerala in brief

This page lists 49 places under Kerala, with 49 different codes between them. Counted without the leading 0: 22 have a three-digit code, so their landline numbers have seven digits and 27 have a four-digit code, so their landline numbers have six digits. The lowest code is 0460 (Taliparamba) and the highest is 04998 (Uppala).

How the codes are numbered

After the 0, the codes begin with 49 (19 places, such as Alathur), 48 (16 places, such as Adimaly), 47 (12 places, such as Adoor) and 46 (2 places, such as Taliparamba). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 4 is also used in Andhra Pradesh and Telangana, Lakshadweep and Tamil Nadu and Puducherry.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town. One place appears under more than one code: Taliparamba (0460, 04982). A name can belong to two different towns, so check the district with the person you are calling.

Questions about STD codes in Kerala

What is the STD code of Taliparamba?

The STD code of Taliparamba is 0460. From outside India, dial +91 460 and then the landline number.

How many digits does a landline number in Kerala have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Kerala have the shortest STD codes?

Taliparamba (0460), Tiruvalla (0469) and Attingal (0470).
