How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Bangalore that is 080 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 80 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Bangalore (080), Tumkur (0816), Udupi (0820), Mysore (0821), Mangalore (0824).

The codes of Karnataka in brief

This page lists 181 places under Karnataka, with 181 different codes between them. Counted without the leading 0: 1 has a two-digit code, so its landline numbers have eight digits, 6 have a three-digit code, so their landline numbers have seven digits and 174 have a four-digit code, so their landline numbers have six digits. The lowest code is 080 (Bangalore) and the highest is 08539 (Koppal).

How the codes are numbered

After the 0, the codes begin with 81 (52 places, such as Alur), 83 (52 places, such as Ainapur), 82 (40 places, such as Athani), 84 (27 places, such as Afzalpur), 85 (9 places, such as Deodurga) and 80 (1 place, such as Bangalore). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 8 is also used in Andhra Pradesh and Telangana and Goa.

Shared codes

2 rows name of the table two or more places that share one code, written with a slash between the names: Raibag and Kudchi (08331) and Hukkeri and Sankeshwar (08333). The same code is dialled for each of them. One place appears under more than one code: Gundlupet (08220, 08229). A name can belong to two different towns, so check the district with the person you are calling.

Questions about STD codes in Karnataka

What is the STD code of Bangalore?

The STD code of Bangalore is 080. From outside India, dial +91 80 and then the landline number.

How many digits does a landline number in Karnataka have?

It depends on the code: eight digits with a two-digit code, seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Karnataka have the shortest STD codes?

Bangalore (080), Tumkur (0816) and Udupi (0820).
